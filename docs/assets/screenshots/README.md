# 📸 Folder Screenshot Aplikasi

Folder ini menyimpan tangkapan layar resmi yang dipakai di `README.md` (bagian
**"Tampilan Aplikasi"**). Ganti file di bawah ini dengan screenshot Anda sendiri —
**pertahankan nama file yang sama** agar README tidak perlu diubah.

| Nama file | Tampilan yang diharapkan | Resolusi saran |
|---|---|---|
| `dashboard.png` | Terminal Trading: kartu KPI, strip proteksi modal, Skor Kesiapan Live | 1440×900 |
| `scanner-radar.png` | Tab Market Scanner: **Radar Pasar (Deterministik)** + gauge breadth | 1440×900 |
| `setup-wizard.png` | **Panduan Setup** langkah 4 (Modal & Profil Risiko dengan pratinjau alokasi) | 1440×900 |
| `backtest.png` | Tab Backtest Strategi (single & portofolio, Exit Adaptif) | 1440×900 |
| `bots.png` | Tab Bots: WhatsApp (QR) & Telegram, mode kanal | 1440×900 |
| `reports.png` | Tab Laporan & Kinerja: KPI eksekutif + **Atribusi Strategi** | 1440×900 |

Tips: matikan data pribadi sebelum memotret (saldo asli, nomor WhatsApp admin,
token). Mode PAPER + bahasa apa pun aman untuk dipublikasikan.

Cara cepat mengganti semua:

```bash
# jalankan aplikasi, login admin, lalu potret tiap tab dan timpa file di folder ini
npm start
```
